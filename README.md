# IdadeID Checkout Trigger

Smart Checkout Trigger externo do IdadeID.

## Arquivo público

Depois do deploy na Vercel, o script ficará em:

```html
<script
  src="https://SEU-PROJETO.vercel.app/widget/checkout-trigger.js?v=1.0.0"
  data-site-key="idadeid_pk_...">
</script>
```

## Observação crítica

Este projeto não substitui o loader de acesso atual do IdadeID.
Ele é apenas a camada de acionamento antes do checkout.
